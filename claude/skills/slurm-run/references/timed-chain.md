# timed のジョブを && でつなぐ

`timed` のジョブを `&&` でつなぐと、前が終わってから次を投げるまでのすき間に、待っていた `main` のジョブが始まり、次の `timed` の
ジョブに止められて、メモリとロックを持ったまま待つ（SKILL.md の「時間を記録するジョブ（--timed）」のメモリとロックの確認を
通らない）。後の `timed` のジョブが前の出力を使って `&&` が要るときは、報告に次の 2 つを書く。

- `&&` でつないだ理由（後のジョブが使う前の出力）
- すき間に始まって止められた `main` のジョブ。すき間は `sacct -j <timed のジョブの番号>,… -X -o JobID,Submit,End` の、前のジョブの
  `End` から次のジョブの `Submit` まで（両端を含む）。`sacct -S <最初のジョブの始まり> -X -r main -o JobID,Start,Suspended` のうち、
  `Start` がすき間に入り、`Suspended` が 0 でないものを挙げる
